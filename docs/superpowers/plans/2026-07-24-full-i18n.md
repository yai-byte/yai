# Full i18n Coverage Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Route every remaining user-visible CLI string through `tr()` / `tr_format()` and keep `po/en.po` + `po/zh.po` in sync.

**Architecture:** Keep the existing po-catalog loader. At each print/throw site, wrap English msgids with `tr()`/`tr_format()`. Add matching entries to both po files (en msgstr = msgid; zh msgstr = Simplified Chinese).

**Tech Stack:** C++17, custom `tr`/`tr_format`, gettext-style `.po` files, Makefile, shell smoke tests.

## Global Constraints

- msgid must be English source text
- Do not translate machine-parseable data (IDs, paths, config keys, tab-separated columns)
- Do not add new i18n APIs
- Do not commit unless the user asks
- Preserve existing smoke tests that set `YAI_LANG=en`
